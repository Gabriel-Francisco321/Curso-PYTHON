# Curso de Python

Um repositório educacional com anotações e exemplos práticos sobre os fundamentos da programação em Python.

## Conteúdo

Este projeto é organizado em tópicos fundamentais da linguagem Python:

### Conceitos Básicos
- **helloworld.py** - Primeiro programa em Python
- **print_e_operadores.py** - Função `print()` e operadores básicos
- **zen.py** - O Zen do Python (PEP 20)

### Estruturas de Dados
- **listas.py** - Listas e operações com listas
- **dicionarios.py** - Dicionários e manipulação de dados chave-valor
- **sequencias.py** - Trabalho com sequências em Python
- **strings.py** - Manipulação de strings

### Controle de Fluxo
- **condicoes.py** - Estruturas condicionais (if, elif, else)
- **loops.py** - Estruturas de repetição (for, while)

### Programação Funcional
- **funcoes.py** - Definição e uso de funções

## Objetivo

Este caderno serve como referência prática para aprendizado e consolidação dos conceitos fundamentais de Python, incluindo exemplos de código, explicações e boas práticas.

## Dicas

- Modifique os exemplos para experimentar diferentes variações
- Use como referência ao resolver problemas em Python
